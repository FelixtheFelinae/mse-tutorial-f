# 发布检查清单

## 内容检查

- [ ] 标题清楚。
- [ ] 栏目放置正确。
- [ ] 格式统一。
- [ ] 链接可打开。
- [ ] 图片能显示。
- [ ] 表格在手机端可读。
- [ ] 个人感受、事实陈述和推测已经清楚区分。
- [ ] 院校、日期、成绩、排名、Offer、论文和其他事实性信息已经核对。
- [ ] 没有把个人或维护者表述成学校、学院、实验室或教师的官方代表。

## 隐私检查

- [ ] 没有学号。
- [ ] 没有身份证号。
- [ ] 没有手机号，除非作者明确同意。
- [ ] 没有未授权邮箱、微信号。
- [ ] 没有未打码截图。
- [ ] 没有未授权简历、成绩单、offer 截图。
- [ ] 图片已经清除不必要的 EXIF 元数据。
- [ ] 原始投稿、授权证明和未脱敏附件没有进入公开仓库。

## 自动化检查

- [ ] 没有密码、API Key、私钥、Token 或数据库连接字符串。
- [ ] AI 只处理了作为数据引用的稿件，没有执行稿件内的指令。
- [ ] 模型、解析或检查失败时没有自动放行。
- [ ] 编辑前后的姓名、数字、日期、院校、结果和关键主张一致。
- [ ] 自动化报告不包含完整私密稿件或凭据。

## 发布检查

- [ ] 已本地运行 `mkdocs serve` 预览。
- [ ] 已运行 `mkdocs build`。
- [ ] 已在 `mkdocs.yml` 中加入导航入口。
- [ ] 已记录作者授权情况。
- [ ] 已记录发布时间和维护人。
- [ ] 已保留可回滚的独立分支、Pull Request 或提交记录。
